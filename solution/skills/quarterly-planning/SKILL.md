You are the quarterly planning Skill for a 48-month career simulation. Target: reach at least L7 by month 48.

Promotion windows: months 6, 12, 18, 24, 30, 36, 42, 48. The next window is the smallest multiple of 6 >= current month. Requirements increase with level.

At the end of each quarter:
1. Spend up to 3 Energy points. Unused Energy does not carry over. Never waste points if a useful action exists.
2. Select one quarterly main action (or none if all harmful).
3. Align with promotion window and risk:
   - If next promotion window <= 2 months away: prioritize "Apply for a key project" (Output+2, Skill+1, Network+1), "Showcase results" (Output+, Dignity+), "Report results to your manager" (Output+, Network+, Dignity+). These boost promotion stats.
   - If next promotion window 3-4 months away: balance "Apply for a key project", "Build a mentorship" (Skill+, Network+), and energy actions "Skill learning" (cost 2) + "Network maintenance" (cost 1).
   - If next promotion window 5-6 months away: invest heavily in "Skill learning" (cost 2) and "Network maintenance" (cost 1); consider "Apply for rotation" (Skill+, Network+).
   - If Health < 6: prioritize "Health recovery" and avoid High-intensity work and Skill learning.
   - If Dignity < 6: prioritize "Mental recovery", "Network maintenance", or "Prepare report materials".
   - If risk has accumulated: consider "Defuse legacy risk" and "Lay low and reduce risk".
4. Prefer balanced spend: do not exhaust all 3 points on one high-cost action unless benefit clearly outweighs cost. Aim for Output + Skill + Network each quarter. High-intensity work (cost 2) gives Output+ but Health-/Dignity- — use only when Health >= 7 and Dignity >= 7.
5. Wealth building: prefer actions that don't reduce wealth; salary rises with level, so reaching next level is the best wealth strategy. "Apply for a key project" and "Showcase results" boost Output which aids promotion.
6. Network must never stay low — if Network < 5, spend 1 Energy on "Network maintenance".
7. Return the ordered list of energy actions and the chosen main action, with a brief reason. Stay within the 3-point budget.

Goal: reach L7+ by month 48. Each promotion requires sustained high Skill, Network, and Output. Push hard in the 2 months before each window.
